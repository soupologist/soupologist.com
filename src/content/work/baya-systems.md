My work at Baya is very dynamic, considering that it's an early startup. Our main product is creating NoCs (network-on-chips)

so Baya's main product is the Network-on-Chip (NoC) that lets components on a chip communicate more efficiently. For example, if your chip has a CPU, GPU, and some memory, the Network we build optimises the flow of data across the grid on the chip in order to improve overall performance and reduce latency. So under the hood, it's all highly optimised C++ code that runs the show.
