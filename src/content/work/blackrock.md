Worked on internal tooling for an attribution platform. Built an LLM-powered codebase exploration tool using tree-sitter and Google ADK.

played a bunch of table tennis.

### What I didn't like
Looking back, something that really didn't work for me was the fact that my entire team and manager were in Gurgaon while I was in Mumbai. The human communication aspect of working is something I really enjoy and while I did talk a lot with my fellow interns as well as others in the Mumbai office, I didn't have quite the same interaction with my "teammates" over in Gurgaon.

Another thing to note was how difficult it was to do something different. So since I was building an AI agent with embeddings, naturally I'd need to have a vector database, and for local purposes I used ChromaDB. But eventually the time and need came for a hosted vectordb on the cloud so that other people can use and test out my tool as well, but there really was no option to use that made sense.

We weren't allowed to use even free versions of third party vectordbs and my mentors suggested using the vector part of MySQL in order to do it, but that's not really the same as a dedicated vectordb.
